# Computer Engineering Portfolio

Final portfolio for Jongwookim (Iowa State University, B.S. Computer Engineering).
Single-file static sites, no build step and no installs.

- `index.html`: formal version (default)
- `arcade/index.html`: interactive retro/pixel version with the same content

Open `index.html` directly in a browser, or serve the repository with GitHub Pages (Settings > Pages > Deploy from branch `main`, folder `/`).
